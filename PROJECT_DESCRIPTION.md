# AmazonQ-TerraViz ⭐

## 🎯 Descripción del Proyecto

**AmazonQ-TerraViz** es una herramienta de visualización moderna que demuestra las capacidades avanzadas de **Amazon Q Developer** para generar diagramas interactivos de arquitectura AWS basados en código Terraform.

## 🚀 Propósito

Este proyecto sirve como **prueba de concepto** para mostrar cómo Amazon Q puede:
- Analizar y comprender código Terraform complejo
- Generar interfaces web modernas y funcionales
- Crear visualizaciones interactivas de infraestructura
- Implementar diseños minimalistas con efectos avanzados
- Desarrollar flujos de trabajo completos de DevOps

## 🛠️ Tecnologías Demostradas

### **Amazon Q Developer**
- Generación de código HTML, CSS y JavaScript
- Análisis y parsing de archivos Terraform
- Creación de interfaces de usuario modernas
- Implementación de lógica de negocio compleja

### **Terraform**
- Módulos de infraestructura AWS (VPC, EC2, RDS, ECS, ECR, S3)
- Configuración de redes y subnets
- Mejores prácticas de IaC (Infrastructure as Code)
- Organización modular de recursos

### **Frontend Moderno**
- Diseño minimalista con glassmorphism
- Animaciones CSS avanzadas
- Flujo de tráfico visual interactivo
- Responsive design y UX moderna

## 🎨 Características Destacadas

### **Visualización Inteligente**
- **Parser automático** de código Terraform
- **7 tipos de flujo** de tráfico con colores únicos
- **Iconos grandes** (48px) para servicios AWS
- **Efectos glassmorphism** con backdrop-filter

### **Control en Tiempo Real**
- **Sidebar interactivo** para habilitar/deshabilitar recursos
- **Regeneración instantánea** de diagramas
- **Configuración persistente** durante la sesión
- **Flujo de tráfico direccional** con flechas animadas

### **Arquitectura Completa**
```
🌐 Internet → ⚡ IGW → ⚖️ ALB → 🐳 ECS → 🗄️ RDS
                              ↑
                    📦 ECR + 🗂️ S3
```
