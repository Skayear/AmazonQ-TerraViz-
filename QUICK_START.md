# 🚀 Guía de Inicio Rápido - AWS Architecture Designer

## En 3 pasos simples:

### 1️⃣ Abrir la aplicación moderna
```bash
# Opción A: Doble clic
architecture-diagram.html

# Opción B: Desde terminal
open architecture-diagram.html        # macOS
start architecture-diagram.html       # Windows
xdg-open architecture-diagram.html    # Linux
```

### 2️⃣ Disfrutar el diseño minimalista
- La aplicación carga con un diseño moderno y sidebar organizado
- Ejemplo funcional precargado con flujo de tráfico visual
- Haz clic en **"▶️ Generate"** para ver el diagrama animado
- ¡Observa las líneas de tráfico en movimiento!

### 3️⃣ Controlar recursos en tiempo real
- Usa el **Sidebar** para activar/desactivar servicios con iconos
- Haz clic en **"⚙️ Apply"** para regenerar instantáneamente
- Experimenta con el flujo de tráfico lineal completo

## ⚡ Funciones Principales

| Acción | Resultado |
|--------|-----------|
| 📦 Activar ECR | Muestra repositorio con líneas de flujo púrpura |
| 🗂️ Activar S3 | Agrega almacenamiento con conexiones teal |
| ❌ Desactivar RDS | Oculta base de datos y sus conexiones rojas |
| ⚙️ Apply | Regenera diagrama con animaciones |
| 🔄 Reset | Activa todos los servicios y flujos |
| 🔄 Refresh | Reinicia aplicación (botón header) |

## 🎯 Casos de Uso Rápidos

### Para Presentaciones Ejecutivas
1. Usar el diseño minimalista para impresionar
2. Mostrar flujo de tráfico completo con 7 tipos de líneas
3. Activar/desactivar servicios en vivo durante la demo
4. Iconos grandes perfectos para proyección

### Para Documentación Técnica
1. Activar todos los recursos relevantes
2. Desactivar animaciones para capturas estáticas
3. Usar glassmorphism para documentos modernos
4. Mostrar flujos direccionales con flechas

### Para Training y Workshops
1. Comenzar con Internet + IGW (flujo verde)
2. Agregar Load Balancer (flujo azul)
3. Incluir ECS (flujo naranja)
4. Finalizar con RDS (flujo rojo)
5. Mostrar servicios auxiliares (ECR púrpura, S3 teal)

### Para Debugging de Red
1. Activar solo los componentes problemáticos
2. Seguir las líneas de tráfico para identificar cuellos de botella
3. Usar colores diferenciados para aislar problemas
4. Verificar conectividad con flujos direccionales

## 🎨 Nuevas Características Visuales

- **Glassmorphism**: Efectos de vidrio esmerilado modernos
- **Sidebar organizado**: Controles agrupados por categoría
- **Iconos grandes**: 48px para servicios, 28px para recursos
- **7 flujos de tráfico**: Cada uno con color y velocidad únicos
- **Flechas direccionales**: Indican dirección del tráfico
- **Hover effects**: Transformaciones y sombras dinámicas
- **Header sticky**: Navegación siempre accesible
